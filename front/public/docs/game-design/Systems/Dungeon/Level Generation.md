# Level Generation

## Known Requirements

Levels are generated as coherent spaces and tagged by era, theme, threat, resource bias, and special state. A tracked request can guarantee a compatible objective anchor.

## Questions to Resolve

- Generation algorithm and seed behavior.
- Critical-path, optional-area, and extraction placement constraints.
- Validation against unreachable objectives or impossible resource costs.
- Rules for landmarks, secrets, hazards, and narrative spaces.

## Completion Criteria

Specify generation inputs, output schema, validity checks, debug visualization, and representative generated-level tests.
