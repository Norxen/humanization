# Extraction

## Known Requirements

Extraction converts carried rewards into permanent value. At an extraction opportunity, the player chooses between securing the current run and pushing deeper for greater reward and risk.

## Questions to Resolve

- Extraction frequency and activation cost.
- Whether extraction is immediate, defended, timed, or conditional.
- Escort and incapacitation behavior.
- Mode-specific loss rules.
- Presentation of secured versus unsecured value.

## Completion Criteria

Define extraction states, cancellation rules, failure outcomes, UI requirements, and prototype tuning targets.
