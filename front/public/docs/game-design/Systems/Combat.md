# Combat

## Purpose

Combat is one way to resolve danger, not the only interaction in the dungeon. It must support readable threats, preparation choices, tool use, avoidance, and meaningful resource costs.

## Dependencies

Combat decisions depend on enemy behavior, player actions, damage rules, equipment, encounter composition, and run failure rules.

## Completion Criteria

The combat section is reviewable when the player verbs, timing model, damage model, enemy roles, and prototype encounter targets are defined together.
