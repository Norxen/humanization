# Systems

## System Map

- [Core Loop](Systems/Core%20Loop.md) defines the complete cause-and-effect cycle.
- [Hub](Systems/Hub.md) turns secured value into civilization progress and new objectives.
- [Dungeon](Systems/Dungeon.md) creates exploration, uncertainty, and risk.
- [Progression](Systems/Progression.md) controls permanent capability and era advancement.
- [Combat](Systems/Combat.md) defines direct threat resolution.

## Integration Rule

Every system must identify its inputs, player decisions, outputs, failure behavior, and effect on at least one other system.
