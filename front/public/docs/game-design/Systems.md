# Systems

## System Map

- [Core Loop](Systems/Core%20Loop.md) defines the complete cause-and-effect cycle.
- [Combat](Systems/Combat.md) defines direct threat resolution.
- [Dungeon](Systems/Dungeon.md) creates exploration, uncertainty, objectives, extraction, and risk.
- [Hub](Systems/Hub.md) turns delivered value into civilization progress and new objectives.
- [Progression](Systems/Progression.md) controls resources, knowledge, equipment, inventory, player growth, and era advancement.

## Integration Rule

Every system must identify its inputs, player decisions, outputs, failure behavior, and effect on at least one other system.

Separate child documents are justified only when a topic has distinct ownership, substantial rules, or cross-system dependencies that make the parent difficult to use.
