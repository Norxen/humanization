# Vision

## Purpose

This section defines what the game is trying to make the player feel and which promises every system must support. The working title is **Roguelike Civilization Rebuilder**.

## Vision Statement

The player is an engineer who repeatedly enters a dangerous underground archive, secures people, resources, and knowledge, and uses them to rebuild a visible human civilization era by era.
