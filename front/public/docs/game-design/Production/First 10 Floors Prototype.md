# First 10 Floors Prototype

## Purpose

The first prototype should prove the core loop before the full game is built.

Do not start with 300 floors, all eras, or every hub system. Start with 10 floors that feel good.

## Prototype Goal

Create a playable loop where the player can:

```text
Enter dungeon
-> Fight enemies
-> Gather resources
-> Reach extraction
-> Return to hub
-> Build one upgrade
-> Unlock one deeper objective
```

## Included Systems

### Hub

- One shelter screen or small 3D area.
- Workbench.
- Storage.
- One rescued or starting NPC.
- One upgrade: build generator or improve workbench.

### Dungeon

- 10 floors or rooms.
- Basic enemies.
- Basic resources.
- One mini-boss.
- One extraction point.
- One rare blueprint.

### Progression

- Gather resources.
- Extract safely.
- Build one upgrade.
- Unlock one new tool or objective.

### Player

- Basic attack.
- Dodge or movement skill.
- Scanner ability.
- One deployable gadget.

## Prototype Resources

| Resource | Source | Use |
| --- | --- | --- |
| Scrap | Common rooms and enemies. | Workbench upgrade. |
| Medicinal Fungus | Organic rooms. | Healing kits. |
| Copper | Resource rooms. | Generator parts. |
| Damaged Memory Core | Mini-boss or lore room. | Unlock first research. |

## Prototype Rooms

| Room | Purpose |
| --- | --- |
| Entry Room | Start the run and teach movement. |
| Combat Room | Teach basic fighting. |
| Resource Room | Teach gathering. |
| Hazard Room | Teach risk without combat. |
| Lore Room | Introduce The Cradle. |
| Survivor Room | Add an optional rescue decision. |
| Mini-Boss Room | Test combat and preparation. |
| Extraction Room | Let the player leave with rewards. |

## Prototype Enemies

| Enemy | Function |
| --- | --- |
| Lurker | Basic melee enemy. |
| Spitter | Ranged pressure enemy. |
| Burrower | Ambush enemy near resource nodes. |
| Gate Husk | Mini-boss guarding extraction or blueprint. |

## Example 30-Minute Session

### Step 1: Hub Preparation

The player checks the shelter.

Current needs:

- The clinic needs medicinal fungus.
- The workbench needs scrap.
- The generator needs copper.

The player crafts:

- 2 healing kits.
- 1 scanner battery.
- 1 shock trap.

Objective:

> Reach Floor 10 and extract with copper and the damaged memory core.

### Step 2: Floors 1-5

The player gathers scrap, fights basic enemies, and finds a small lore log about The Cradle.

The player learns:

- Combat basics.
- Gathering.
- Scanner use.
- Carrying limits.

### Step 3: Floors 6-9

Pressure increases.

The player finds:

- Medicinal fungus.
- Copper.
- A wounded survivor or survivor clue.
- A locked archive room.

The player must decide what to carry and whether to spend supplies before the mini-boss.

### Step 4: Floor 10

The player fights the Gate Husk and reaches extraction.

Rewards:

- Copper.
- Scrap.
- Medicinal fungus.
- Damaged Memory Core.
- Optional rescued survivor.

### Step 5: Hub Upgrade

Back at the hub:

- The workbench upgrade becomes available.
- The memory core unlocks the generator objective.
- The NPC creates a new request.
- The next run has a clear purpose.

## Success Criteria

The prototype works if:

- The player understands why they entered the dungeon.
- Combat and gathering are readable.
- Extraction creates tension.
- Returning to the hub feels rewarding.
- The first upgrade changes what the player can do.
- The player wants to start one more run.

## Prototype Rule

If the 10-floor loop is not fun, do not add more floors yet. Improve the loop first.
