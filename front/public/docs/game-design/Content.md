# Content

## Purpose

Content defines reusable families, authoring requirements, and production costs. It references system rules instead of duplicating them.

Content volume is intentionally undefined. Counts should only be selected after the relevant system templates and complexity multipliers are understood.

## Definition

[Content Requirements](Content/Content%20Requirements.md) owns the shared schemas and unresolved production questions for enemies, bosses, equipment, locations, and survivors.
