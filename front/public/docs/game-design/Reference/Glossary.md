# Glossary

| Term | Definition |
| --- | --- |
| The Cradle | Underground civilization reconstruction archive containing zones, people, knowledge, and infrastructure. |
| Hub | The walkable settlement where secured expedition value becomes permanent progress. |
| Survey Mode | Candidate information-focused expedition mode for mapping and discovering future opportunities. |
| Expedition Mode | Candidate objective-focused expedition mode with stronger commitment and generation influence. |
| Extraction | The process that secures carried rewards and returns the player to the hub. |
| Secured | Objective value acquired during a run but not yet permanently delivered to the hub. |
| Delivered | Extracted value that has reached the hub and become persistent. |
| Era | A civilization capability band that changes buildings, content, technology, and campaign state. |
| Request | A hub need that can become a tracked dungeon objective. |
| Return Protocol | Humanity's deeper plan to prevent extinction from becoming permanent. |
| The Curator | Damaged AI responsible for preserving knowledge and managing reconstruction systems. |
