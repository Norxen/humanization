# Accessibility

## Required Areas

- Complete remapping and controller support.
- Text size, contrast, color-independent meaning, and readable diagrams.
- Subtitles, captions, directional sound alternatives, and volume categories.
- Motion, flashing, camera shake, and timing adjustments.
- Difficulty assists that preserve design intent while reducing execution barriers.

## Completion Criteria

Select target standards, assign requirements to affected systems, define test devices and assistive scenarios, and include accessibility acceptance criteria in every production milestone.
